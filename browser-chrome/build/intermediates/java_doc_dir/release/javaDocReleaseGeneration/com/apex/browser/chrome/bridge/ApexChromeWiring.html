Class ApexChromeWiring

  • All Implemented Interfaces:
    com.apex.browser.engine.BrowserEngine.BrowserUiCallback 
    
public final class ApexChromeWiring
 implements BrowserEngine.BrowserUiCallback

    ApexChromeWiring —— 把通用 NeonChromeWiring 接到本项目 BrowserEngine 的真实接线器。

    职责（全部收敛在这里，引擎与 chrome UI 保持互不感知）：

    • TabOperations 六行直通：chrome 标签命令 → 引擎 newTab/switchTab/closeTab；

    • 链式接管：活动 WebView 的 client 链式包一层——引擎自动化回调零破坏， JS 弹窗/网页权限/下载/进度/标题/查找全部导入 chrome 层；

    • 人机双通道弹窗：WAITING_HUMAN（浮窗开着）→ 人裁决； 无人值守（AGENT_DRIVING/HIDDEN）→ AgentDialogPolicy 安全默认 （ALERT 自动确认 / CONFIRM 默认拒绝 / PROMPT 不接管按取消回放）；

    • 无人值守权限：非 WAITING_HUMAN 时网页权限一律安全拒绝 （对齐引擎旧 onPermissionRequest 的 deny 语义，但不打断状态机）；

    • 上下文回写：弹窗/下载事件回写 engine.lastDialog / lastDownload， Agent 侧 snapshot 注入与 browser_download_list 工具语义保持不变；

    • 状态联动：订阅引擎 BrowserUiCallback，会话状态变化即 resync（浮窗展开、 Agent 开新标签、渲染进程重建后，chrome 数据源自动对齐引擎实况）。

    用法（BrowserOverlay 内）：

    val gateway = wiring.gateway      // 交给 BrowserChrome(gateway = ...)
wiring.onActiveWebViewChanged = { view -> rebindWebView(view) }

    库化改造：去 Hilt —— 单例语义由 ApexChromeWiringFactory 提供（F1：库不依赖 DI 框架）。
